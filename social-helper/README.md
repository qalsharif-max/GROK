# HNAK Organic Studio

A social media helper focused on **organic posts** for [HNAK](https://www.hnak.com) — Saudi e-commerce that blends international brands with local craft (including Min Hena).

## What’s inside

- **Post library** — 16 ready Arabic + English organic captions
- **Pillars** — Local, Lifestyle, Education, Community, Trust, Seasonal, Soft sell
- **Platforms** — Instagram, Snapchat, TikTok, X, LinkedIn
- **Draft workshop** — generate a new caption from topic + audience cues
- **Copy + visual brief** — each post includes hashtags, CTA, and shoot notes

## Run locally

```bash
cd social-helper
npm install
npm run dev
```

## Organic playbook (short)

1. **Help first** — tips and myths before SKUs  
2. **Belong** — Saudi context and Min Hena pride  
3. **Invite** — one clear question; reply in the first hour  

Hard-sell offers work better after a week of native content.
